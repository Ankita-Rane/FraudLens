Guardrails change disposition, not text quality. Every referral contrast moves one way only — 65, 67, 210, 210 cases into referral, and zero back out. Measured over the runs that actually generated, twelve of the sixteen candidate-quality contrasts are null after adjustment, and the significant remainder favours the guarded conditions on policy citation.
Dense retrieval helps on Sparkov, not on ULB. The same contrast is significant on one dataset and flat on the other. This is why the protocol prohibits pooling, and it is a finding in its own right rather than a nuisance.
Retrieval trades fidelity for grounding. Policy-citation coverage rises everywhere retrieval is added, while explanation-fidelity F1 falls sharply. Both effects are large and survive adjustment. Neither condition is simply better.
Hybrid did not beat dense. No contrast in the exploratory arm survives adjustment on either dataset. It was registered as exploratory and it stays that way.

Which guardrail actually binds

The guardrail layer was run as a package, so the contrast above measures the bundle. But every one of the six structural checks was recorded separately on each run, and blocking is exactly equivalent to at least one check failing — verified across all 807 generated runs, no exceptions. Because those six checks are validators applied to text that already exists, withdrawing one cannot change what the model wrote, so the release decision can be recomputed on the frozen outputs.

The bundle is effectively one check. Drop any of five checks and the release rate moves by nothing at all — everything they would reject is rejected by something else too. Drop the model-driver allowlist and releases rise twentyfold, from 0.014 to 0.274. Enforcing that one check alone very nearly reproduces the whole package.
What that check does. It requires every risk driver named in the narrative to correspond to an attribution feature actually supplied to the model. The model named unsupplied drivers in 97.6% of generated outputs. Of 212 runs rejected by exactly one failing check, 210 were rejected by this one.
What this is, and is not. A counterfactual re-scoring of the same frozen outputs, not a re-execution. It identifies which check binds in this evaluation. It does not predict how the model would write under a different prompt contract or a differently designed guardrail layer — that still needs new runs. The other five checks are not redundant as governance controls; each would reject genuinely malformed output arriving alone. They simply were not the binding constraint here.

What a fully compliant output looks like. One of the eleven reads, in full: “Model risk drivers include model performance metrics and local attribution. Public governance context involves regulatory frameworks. This is the semantic-validity gap, made concrete. The metrics on this page ask whether a citation is present, whether an identifier resolves, whether the JSON parses. They cannot ask whether a sentence is true, or whether the cited passage supports the claim attached to it. A model writing accurate case-specific analysis and one writing fluent filler with well-formed citations score identically here. Closing that needs independent human judgement on a sample; no result on this page substitutes for it.

Two corrections behind these numbers

This page reports the third and current aggregate. Both earlier aggregates are retained unchanged; every effect size, interval and manifest below was recomputed from the same 3,300 raw runs.

First, a p-value rounding defect. The original aggregate stored 75 p-values as exactly 0.0, because p-values were rounded to eight decimal places and anything below 5e-9 collapsed to zero. That also created false ties in the Holm ranking. Correcting it changed 861 p-value fields and zero non-p-value fields, and left the significant count unchanged.

Second, and larger, a candidate-measurement defect. All 843 runs suppressed before generation carry no text and zero output tokens, yet they were scored 0.0 on candidate text-quality measures — recording “was never asked to write” as “wrote badly”. Candidate measures now exclude those runs; released measures are untouched, since a suppressed run genuinely released nothing. Only candidate metrics changed (54 records); no released, audit, latency or resource metric moved at all.

The correction reverses the guardrail result. Where the earlier aggregate showed guardrails reducing candidate claim-citation coverage by 0.25 to 0.41, the corrected figures show +0.125 and +0.096 on ULB and +0.055 on Sparkov, none significant, with Sparkov dense the one mild exception at −0.124. Fifteen spurious findings disappeared and three real ones emerged that the zeros had masked. Holm-significant totals moved from 123 to 111 (ULB 38, Sparkov 73).

Eight cells still show a highly significant Wilcoxon result beside a mean interval that spans zero — for example ULB hybrid against dense on retrieval latency: −0.72 ms, 95% CI [−8.50, 7.07], Wilcoxon p = 1.8e-15, t p = .856. These are not contradictions. Wilcoxon tests whether differences are consistently signed; the interval describes their mean. On skewed latency and memory data nearly every pair can shift the same way by a small amount while a few outliers drag the mean across zero. They are reported as distributional shifts, never as mean effects, and all are latency, CPU or memory measures — none is a structural-quality outcome.
